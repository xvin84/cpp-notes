**Категория значения (value category) отвечает на вопрос, материален ли
результат выражения — существует ли он в виде объекта в памяти.** Материальная
категория — **lvalue**, нематериальная — **prvalue**.

## Зачем нужно

Без категорий непонятно, почему одним выражениям можно присвоить, а другим нет:

```cpp
(x = y) = 5;  // компилируется, x == 5
x + y = 10;   // ошибка
```

Присваивание возвращает саму переменную `x`, а сложение — просто число, у
которого нет места в памяти. Записывать некуда.

## Как работает

Каждое [[20-terms/vyrazheniya-i-operatory|выражение]] характеризуется двумя вещами:
**типом** возвращаемого значения и **категорией значения**. Пусть изначально
`x == 5`, строки выполняются по порядку:

| Выражение | Тип | Побочный эффект | Категория |
|---|---|---|---|
| `x + y` | `int` | нет | prvalue |
| `x = 5` | `int` | в `x` хранится 5 | lvalue (`x`) |
| `x *= 2` | `int` | в `x` хранится 10 | lvalue (`x`) |
| `y + (x *= 6)` | `int` | в `x` хранится 60 | prvalue |
| `x / 2.` | `double` | нет | prvalue |

lvalue соответствует месту в памяти, поэтому может стоять слева от
присваивания (за некоторыми исключениями) и быть операндом
[[20-terms/inkrement-i-dekrement|инкремента]]. Отсюда тексты ошибок:

```cpp
5 = x;       // error: lvalue required as left operand of assignment
x * y = 10;  // error: lvalue required as left operand of assignment
++5;         // error: lvalue required as increment operand
```

### Критерий: можно ли взять адрес

Операция `&` применима только к lvalue, поэтому возможность взять адрес —
удобный практический тест:

```cpp
&x, &(x = 8), &(++x);   // lvalue: можно
&5, &(x + 8), &(x++);   // prvalue: нельзя
```

| lvalue | prvalue |
|---|---|
| имя переменной `x` | литерал `5` |
| присваивание `x = 8`, `x += 1` | арифметика `x + 8` |
| префиксный `++x`, `--x` | постфиксный `x++`, `x--` |
| разыменование `*p` | |

Разыменование [[20-terms/ukazatel|указателя]] возвращает lvalue — поэтому через `*p`
можно присваивать.

## Тонкости

> [!info] Не из лекции
> - «Исключения» из правила «lvalue можно присвоить» — например,
>   `const`-переменная: она lvalue, адрес взять можно, а присвоить нельзя.
> - Стандарт делит выражения на три категории: lvalue, prvalue и xvalue.
>   Третья появится вместе с `std::move` и move-семантикой; общее название
>   lvalue и xvalue — glvalue, prvalue и xvalue — rvalue.
> - Строковый литерал `"abc"` — исключение среди литералов: он lvalue, у него
>   есть адрес.

## Частые ошибки

- Путать тип и категорию: `x = 5` и `x + 5` оба `int`, но категории разные.
- Считать, что всё, что «содержит переменную», — lvalue. `y + (x *= 6)` —
  prvalue: снаружи сложение.
- Ожидать, что `x++` вернёт сам `x`.
