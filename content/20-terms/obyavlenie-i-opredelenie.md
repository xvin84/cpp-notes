**Объявление (declaration) сообщает компилятору, что такое имя существует.
Определение (definition) действительно создаёт объект.**

## Зачем нужно

В C++ имя должно быть объявлено до использования. Этот код не компилируется,
хотя `x` — настоящая глобальная переменная:

```cpp
int main() {
  int y = 2;
  std::cout << x + 3 * y << '\n';  // ошибка
  return 0;
}

int x = 1;
```

В момент чтения строки с `std::cout` компилятор ещё не знает, что такое `x`.

## Как работает

Имя можно заранее объявить, а переменную определить позже. Для этого есть
ключевое слово `extern`:

```cpp
int main() {
  int y = 2;
  extern int x;  // объявление без определения
  std::cout << x + 3 * y << '\n';
  return 0;
}

int x = 1;  // определение x
```

`extern int x;` объекта не создаёт — только обещает компилятору, что
переменная `x` типа `int` где-то определена. Создаёт её строка `int x = 1;`.

Обычное `int x;` внутри функции — это объявление и определение сразу: объект
уже существует, хотя начального значения у него нет. Об этом —
[[20-terms/inicializaciya-peremennyh|Инициализация переменных]].

## Тонкости

- В учебном коде проще писать глобальные переменные до функций, и `extern`
  не понадобится.
- Различие объявления и определения дальше будет встречаться постоянно:
  в функциях, заголовочных файлах и раздельной компиляции — см.
  [[20-terms/podklyuchenie-zagolovkov|Подключение заголовков]] и [[20-terms/kompilyaciya-i-sborka|Компиляция и сборка]].
- Объявление делает имя доступным, но только с места объявления и в пределах
  его [[20-terms/oblast-vidimosti|области видимости]].

## Частые ошибки

- Определить глобальную переменную ниже функции, которая её использует, и
  удивляться `was not declared in this scope`.
- Считать, что объявление всегда создаёт объект: `extern int x;` ничего
  не создаёт.
