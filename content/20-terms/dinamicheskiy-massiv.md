**Динамический массив (dynamic array) — массив, созданный в
[[20-terms/dinamicheskaya-pamyat|динамической памяти]] выражением `new T[n]`.** Его
размер может быть известен только во время работы программы. Освобождается он
через `delete[]`.

## Зачем нужно

Размер обычного [[20-terms/massiv|массива]] обязан быть константой времени компиляции:

```cpp
int n = 10;
int a[n]{1, 2, 3};             // стандартом запрещено, но компиляторы позволяют
int* b = new int[n]{1, 2, 3};  // Ok
```

GCC с `-pedantic` выдаёт для первой строки `ISO C++ forbids variable length
array 'a'`. У `new[]` такого ограничения нет.

## Как работает

`new T[n]` создаёт `n` элементов подряд и возвращает [[20-terms/ukazatel|указатель]] на
нулевой:

```cpp
int* array = new int[10];
array[3] = 7;  // индексирование работает как у массива
// ...
delete[] array;
```

**Память из `new[]` освобождается только `delete[]`.**

Результат — указатель на элемент, а не массив, поэтому [[20-terms/sizeof|sizeof]] видит
указатель:

```cpp
sizeof(new int[10]) == sizeof(int*);  // 8
sizeof(*array) == sizeof(int);        // true
```

Число элементов через `sizeof` не узнать — его хранят в отдельной переменной.

### Многомерный динамический массив

Моделируется массивом массивов: массив указателей, каждый из которых указывает
на свою строку:

```cpp
int** array = new int*[n];
for (int i = 0; i < n; ++i) {
  array[i] = new int[m];
}

array[i][j];  // как у обычного двумерного

for (int i = 0; i < n; ++i) {
  delete[] array[i];
}
delete[] array;
```

Освобождают в обратном порядке: сначала строки, потом массив указателей.

## Тонкости

> [!info] Не из лекции
> - `new int[10]` не инициализирует элементы, `new int[10]()` и
>   `new int[10]{}` заполняют нулями.
> - Если инициализаторов больше, чем `n`, `new int[n]{1, 2, 3}` бросает
>   `std::bad_array_new_length` (GCC 16.2, `n == 2`).
> - `delete` вместо `delete[]` — неопределённое поведение. GCC предупреждает
>   (`-Wmismatched-new-delete`), AddressSanitizer сообщает
>   `alloc-dealloc-mismatch`.
> - Строки массива массивов лежат в разных местах памяти, а не подряд, как
>   у `int[n][m]`.

## Частые ошибки

- `delete array;` вместо `delete[] array;`.
- Удалить `array` раньше строк — указатели на строки теряются, утечка.
- Пытаться узнать длину через `sizeof(array) / sizeof(int)`.
- Читать элементы `new int[n]` до записи.
