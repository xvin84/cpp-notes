**`sizeof` — унарная операция, возвращающая размер в байтах.** Применённая к
типу, даёт размер объекта этого типа; применённая к выражению — размер типа
его результата. **Выражение при этом не вычисляется.**

## Зачем нужно

Размеры типов в C++ стандартом не зафиксированы — `sizeof(long)` на Windows и
Linux разный (см. [[20-terms/celochislennye-tipy|Целочисленные типы]]). `sizeof` узнаёт размер для текущей
платформы. Он же нужен для подсчёта байт при ручном выделении памяти и для
[[20-terms/arifmetika-ukazateley|арифметики указателей]], где шаг — `sizeof(T)`.

## Как работает

```cpp
long long x;

sizeof(int);    // размер типа
sizeof('a');    // 1
sizeof(1 / 0);  // 4
sizeof(x = 1);  // 8 (x не меняется!)
sizeof(++x);    // 8 (x не меняется!)
```

Операнд `sizeof` компилятор только анализирует: определяет тип выражения и
подставляет его размер. Деления на ноль во второй строке нет, присваивания в
третьей тоже нет — код для них не генерируется.

`sizeof(char)` равен единице по определению — это и есть байт C++, см.
[[20-terms/simvolnyy-tip-char|Символьный тип char]].

## Тонкости

- `sizeof(x + y)` для двух `short` равен 4: тип выражения — `int` после
  продвижения, см. [[20-terms/arifmeticheskie-preobrazovaniya-tipov|Арифметические преобразования типов]].
- Скобки обязательны для типа (`sizeof(int)`), для выражения не обязательны:
  `sizeof x`.

> [!info] Не из лекции
> - Последний пункт в лонгриде не упоминается.
> - Результат имеет беззнаковый тип `std::size_t` — со всеми ловушками
>   [[20-terms/bezznakovye-tipy|беззнаковых]] при сравнении с отрицательными числами.

## Частые ошибки

- Писать побочный эффект внутри `sizeof` и ждать, что он выполнится.
- Считать, что размер типа одинаков на всех платформах.

## Углубление — L04

Для [[20-terms/massiv|массива]] `sizeof` возвращает суммарный размер, отсюда способ
посчитать элементы:

```cpp
int array[10];
sizeof(array);                // 40
sizeof(array) / sizeof(int);  // 10
```

Это одно из мест, где массив **не** превращается в указатель. Для указателя
на тот же массив результат другой:

```cpp
int* p = array;
sizeof(p);  // 8
```

То же с [[20-terms/dinamicheskiy-massiv|динамическим массивом]]: `new[]` возвращает
указатель, и `sizeof(new int[10]) == sizeof(int*)`. Сама строка ничего не
выделяет — операнд `sizeof` не вычисляется.
