**Область действия переменной — часть программы, в которой объект существует.**
Отвечает на вопрос «где объект есть», а не «где его можно назвать по имени» —
второе называется [[20-terms/oblast-vidimosti|областью видимости]].

> [!info] Не из лекции
> Английского оригинала в материалах нет. Ближайшие понятия стандарта —
> lifetime (время жизни объекта) и storage duration (длительность хранения).
> В части русской литературы «областью действия» называют как раз scope —
> при чтении других источников стоит проверять, что имеется в виду.

## Зачем нужно

У переменной есть не только тип и значение. Важно ещё, где она существует и где
к ней можно обратиться по имени. На маленьких программах это кажется очевидным,
но как только появляются вложенные блоки, одинаковые имена и глобальные
переменные, без этих правил код превращается в угадайку.

## Как работает

### Автоматические переменные

Обычная локальная переменная, объявленная внутри функции, действует с места
объявления до ближайшего конца блока, в котором объявлена. Такие переменные
называются **автоматическими**:

```cpp
int main() {
  int x;
  {
    float y;
    {
      bool b;
      {
        char c;
      }  // здесь заканчивается действие c
    }  // здесь заканчивается действие b
  }  // здесь заканчивается действие y
}  // здесь заканчивается действие x
```

«Автоматическая» — потому что программист не пишет отдельную команду
освобождения памяти. Объект появляется при входе в нужную часть программы
и исчезает при выходе из неё.

Блок — составной оператор в фигурных скобках, см. [[20-terms/vyrazheniya-i-operatory|Выражения и операторы]].
Именно он задаёт границы: после закрывающей скобки переменной уже нет.

```cpp
int main() {
  int x = 1;

  {
    int y = 2;
    std::cout << x + 3 * y << '\n';
  }  // здесь y уже уничтожена

  return y;  // ошибка: 'y' was not declared in this scope
}
```

### Глобальные переменные

Переменная, объявленная вне функций, называется **глобальной**. Она существует
всё время работы программы:

```cpp
int x = 1;

int main() {
  int y = 2;
  std::cout << x + 3 * y << '\n';
  return 0;
}
```

Но существовать всё время работы — не то же самое, что быть доступной отовсюду.
Имя должно быть объявлено до использования: глобальная переменная, определённая
ниже `main`, внутри `main` не видна, пока её не объявить через `extern` —
см. [[20-terms/obyavlenie-i-opredelenie|Объявление и определение]].

### Переменные в заголовках циклов и условий

Имя можно объявить прямо в `if`, `while` или `for`. У `for` область действия
сущности, объявленной в `init`, совпадает с областью самого оператора `for` —
после цикла счётчика уже нет. Подробнее — [[20-terms/cikly|Циклы]].

## Тонкости

- Область видимости не бывает больше области действия: нельзя увидеть по имени
  объект, который уже не существует. Меньше — бывает: глобальная `x` существует,
  пока выполняется `main`, но её имя может скрыть локальная `x`.
- Блок можно поставить просто так, без `if` и цикла, чтобы ограничить время
  жизни временной переменной:

  ```cpp
  int answer = 0;
  {
    int temporary = 40 + 2;
    answer = temporary;
  }
  // temporary здесь уже нет
  ```

  Чем меньше часть программы, в которой видна переменная, тем проще понять,
  где её могут изменить.

## Частые ошибки

- Объявить переменную внутри блока `if` или цикла и попытаться прочитать её
  после блока.
- Считать, что раз глобальная переменная существует всю программу, к ней можно
  обратиться из любой строки файла.
