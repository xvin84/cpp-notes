# Курс C++ МФТИ

Точка входа в базу. Отсюда — ко всем лекциям и темам курса.

## Как этим пользоваться

1. Материалы новой лекции кладёшь в `90-Входящие/`.
2. Запускаешь `/lecture` — ассистент читает материалы и показывает план конспекта
   и список терминов.
3. Правишь план, подтверждаешь — конспект и заметки терминов появляются в базе
   со статусом `draft`.
4. Читаешь, дополняешь, заполняешь `## Своими словами` и `## Вопросы`,
   поднимаешь `status` до `read`, позже до `mastered`.

## Термины по темам

Заполняется по мере роста базы. Полный список — папка `20-Термины/`,
фильтр по тегам работает через поиск Obsidian.

- **Память и указатели** — `#cpp/memory`
- **ООП** — `#cpp/oop`
- **Шаблоны** — `#cpp/templates`
- **STL** — `#cpp/stl`
- **Инструменты и сборка** — `#cpp/tooling`

## Практика

Решения задач — `40-Практика/`. Правила оформления кода и команды проверки
перед сдачей: [[Кодстайл курса]].

## Статусы

- `draft` — написано ассистентом, мной не проверено.
- `read` — прочитал, согласен, что верно.
- `mastered` — могу объяснить без подглядывания.

Найти всё непроверенное: поиск по базе `[status:draft]`.
Термины одной темы: `path:20-Термины tag:#cpp/memory`.

## Структура базы

- `10-Лекции/` — конспекты лекций.
- `20-Термины/` — атомарные заметки на сквозные понятия.
- `30-Код/` — исходники примеров с лекций и разборы.
- `40-Практика/` — мои решения задач + конфиги проверки кодстайла.
- `90-Входящие/` — сырьё, которое ещё не разобрано.
- `99-Шаблоны/` — шаблоны заметок.
